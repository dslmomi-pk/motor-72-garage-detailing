Welcome to **MOTOR 72 — Garage & Detailing**, an automotive care and garage essentials storefront concept built for car enthusiasts, detailing professionals, and drivers who believe every vehicle deserves attention beyond the ordinary.

From premium cleaning supplies and microfiber towels to polishing equipment, interior care products, garage tools, and automotive accessories, MOTOR 72 brings together the essentials for keeping vehicles clean, protected, organized, and looking their best.

## 🚀 Getting Started

Once the storefront files have been added to the repository:

1. Clone or download the repository.
2. Open the project folder in your preferred code editor.
3. Review the HTML, CSS, JavaScript, and product catalog files.
4. Run the site through a local development server when needed.
5. Check product images, navigation, filters, and shopping interactions.
6. Test the layout at desktop and mobile widths.
7. Publish the completed static site through GitHub Pages.

### Run Locally

If the website loads JSON catalog data through JavaScript `fetch()`, use a local server rather than opening `index.html` directly through a `file://` URL.

With Python installed, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🌐 Deploy with GitHub Pages

To publish the completed storefront:

1. Upload the project files to the root of the `motor-72-garage-detailing` repository.
2. Open the repository's **Settings** page.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` directory.
6. Save the settings and wait for deployment to finish.

The published URL generally follows this format:

`https://YOUR-USERNAME.github.io/motor-72-garage-detailing/`

Replace `YOUR-USERNAME` with the GitHub account that owns the repository.
